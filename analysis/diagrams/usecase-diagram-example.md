# Use Case диаграмма: Акторы и сценарии

**Дата создания:** 2024-11-08
**Описание:** Диаграмма юз кейсов и акторов системы

Эта диаграмма показывает кто (акторы) может делать что (юз кейсы) в системе.

---

## Диаграмма

```mermaid
graph TB
    %% Акторы
    User[👤 Пользователь]
    Guest[👥 Гость]
    Admin[👨‍💼 Администратор]
    EmailService[📧 Email-сервис]

    %% Юз кейсы
    UC001[UC-001: Регистрация пользователя]
    UC002[UC-002: Вход в систему]
    UC003[UC-003: Создание заказа]
    UC004[UC-004: Управление пользователями]
    UC005[UC-005: Восстановление пароля]

    %% Связи акторов с юз кейсами
    Guest --> UC001
    Guest --> UC002
    Guest --> UC005

    User --> UC002
    User --> UC003

    Admin --> UC004
    Admin --> UC002

    %% Связи юз кейсов с внешними системами
    UC001 -.-> EmailService
    UC005 -.-> EmailService

    %% Стили
    classDef actor fill:#e1f5ff,stroke:#01579b,stroke-width:2px
    classDef usecase fill:#fff9c4,stroke:#f57f17,stroke-width:2px
    classDef external fill:#f3e5f5,stroke:#4a148c,stroke-width:2px

    class User,Guest,Admin actor
    class UC001,UC002,UC003,UC004,UC005 usecase
    class EmailService external
```

---

## Легенда

### Обозначения:
- **Сплошная линия** → актор инициирует юз кейс
- **Пунктирная линия** -.-> юз кейс использует внешнюю систему
- **Цвета:**
  - 🔵 Голубой - акторы (пользователи системы)
  - 🟡 Желтый - юз кейсы (функции системы)
  - 🟣 Фиолетовый - внешние системы

---

| Актор | Описание | Юз кейсы |
