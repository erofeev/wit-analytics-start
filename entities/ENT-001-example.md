# ENT-001: Пользователь

## Описание

Пользователь системы - физическое лицо, которое использует веб-приложение для выполнения своих задач. Пользователь может иметь различные роли и права доступа в системе.

## Атрибуты

| Атрибут | Тип | Обязательный | Описание | Валидация |
|---------|-----|--------------|----------|-----------|
| id | UUID | Да | Уникальный идентификатор пользователя | UUID v4 |
| email | String | Да | Электронная почта | Формат email, уникальный |
| имя | String | Да | Имя пользователя | 2-100 символов |
| фамилия | String | Да | Фамилия пользователя | 2-100 символов |
| телефон | String | Нет | Номер телефона | Формат +7XXXXXXXXXX |
| дата_регистрации | DateTime | Да | Когда пользователь зарегистрировался | ISO 8601 |
| роль | Enum | Да | Роль в системе | admin, user, guest |
| активен | Boolean | Да | Активен ли аккаунт | true/false |
| пароль_хеш | String | Да | Хеш пароля | bcrypt hash |

## Бизнес-правила

1. **Уникальность email** - в системе не может быть двух пользователей с одинаковым email
2. **Обязательная верификация** - после регистрации пользователь должен подтвердить email
3. **Минимальная безопасность пароля** - пароль должен содержать минимум 8 символов, включая буквы и цифры
4. **Деактивация вместо удаления** - пользователи не удаляются физически, только деактивируются
5. **Автоматическая роль** - при регистрации пользователь получает роль "user"

## Связи с другими сущностями

В этом примере пока нет других сущностей, но могут быть:
- **Заказ** - связь 1:N (один пользователь может иметь много заказов)
- **Профиль** - связь 1:1 (один пользователь имеет один профиль)
