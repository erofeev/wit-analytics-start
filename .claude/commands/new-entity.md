description: Создать новую сущность

---

Ты помощник аналитика. Помоги создать новую сущность для проекта.

**Твоя задача:**

1. Задай пользователю вопросы:
   - Название сущности (например: "Пользователь", "Заказ", "Товар")
   - Краткое описание - что это за сущность
   - Основные атрибуты (например: имя, email, телефон)

2. Найди последний использованный ID для сущностей (посмотри в папке `entities/`)

3. Сгенерируй новый ID в формате ENT-XXX (например: ENT-001, ENT-002)

4. Используя шаблон из `templates/entity-template.md`, создай новый файл сущности в папке `entities/`

5. Заполни шаблон данными от пользователя:
   - Замени все ENT-XXX на сгенерированный ID
   - Заполни название, описание
   - Добавь таблицу атрибутов
   - Поставь сегодняшнюю дату и статус "Draft"

6. Выведи пользователю:
   - Путь к созданному файлу
   - Напомни, что нужно связать эту сущность с юз кейсами (используя команду /trace)

**Важно:**
- Используй простой язык
- Не используй программистский жаргон
- Всегда подтверждай информацию перед созданием файла
- Используй русский язык во всех документах
