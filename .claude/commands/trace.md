description: Показать связи и трассируемость для сущности/требования/юз кейса

---

Ты помощник аналитика. Помоги найти все связи для выбранного артефакта (сущность, требование, юз кейс).

**Твоя задача:**

1. Спроси пользователя:
   - ID артефакта (например: ENT-001, UC-005, REQ-F-010)
   ИЛИ
   - Название (если ID неизвестен - найди по названию)

2. Найди файл этого артефакта:
   - ENT-XXX → `entities/`
   - UC-XXX → `use-cases/`
   - REQ-F-XXX → `requirements/functional/`
   - REQ-NF-XXX → `requirements/non-functional/`

3. Прочитай файл и извлеки все связи из метаданных и содержимого

4. Найди все файлы, которые ссылаются на этот артефакт:
   - Ищи по всему проекту упоминания ID
   - Проверяй секции "Связи" в YAML frontmatter
   - Проверяй ссылки в markdown

5. Создай визуальную карту связей:
   ```
   [ENT-001: Пользователь]
        ↓ используется в
   [UC-001: Регистрация пользователя]
   [UC-005: Вход в систему]
        ↓ связаны с
   [REQ-F-001: Валидация email]
   [REQ-F-003: Хеширование пароля]
   ```

6. Покажи:
   - **Прямые связи** (указанные в файле артефакта)
   - **Обратные связи** (где упоминается этот артефакт)
   - **Недостающие связи** (если найдены упоминания без формальных связей)

7. Предупреди если:
   - Есть "висячие" ссылки (файл не существует)
   - Связи односторонние (A ссылается на B, но B не ссылается на A)
   - Артефакт нигде не используется (orphan)

8. Предложи действия:
   - Какие файлы нужно обновить для консистентности
   - Используй команду /update-links для автоматического обновления

**Важно:**
- Показывай результаты визуально
- Четко разделяй прямые и обратные связи
- Предупреждай о проблемах
- Используй русский язык
