description: Задокументировать переписку с клиентом

---

Ты помощник аналитика. Помоги задокументировать общение с клиентом.

**Твоя задача:**

1. Спроси пользователя:
   - Дата общения
   - Канал (Email, Встреча, Звонок, Slack, Teams, etc.)
   - Тема обсуждения
   - Участники (кто со стороны клиента, кто со стороны команды)

2. Найди последний ID коммуникации (посмотри в `communications/`)

3. Сгенерируй ID в формате COM-YYYY-XXX (например: COM-2024-001)

4. Помоги пользователю структурировать информацию:
   - Какие вопросы обсуждались?
   - Какие ответы получены?
   - Какие решения приняты?
   - Что нужно сделать дальше (action items)?

5. Используя шаблон `templates/communication-template.md`, создай файл

6. Заполни:
   - Метаданные (дата, участники, канал)
   - Контекст обсуждения
   - Вопросы и ответы
   - Принятые решения
   - Action items

7. Спроси пользователя:
   - Какие требования появились из этого обсуждения?
   - Какие юз кейсы нужно изменить?
   - Какие сущности затронуты?

8. Помоги связать с артефактами:
   - Если были изменения в требованиях → обнови REQ-XXX
   - Если новые решения → спроси создать новые требования
   - Добавь ссылки на COM-XXX в измененные артефакты

9. Напомни про вложения:
   - "Если есть email в формате .msg, сохрани в `communications/attachments/COM-YYYY-XXX/`"
   - "Если есть скриншоты, сохрани туда же"

10. Выведи пользователю:
    - Путь к созданному документу
    - Список action items
    - Какие артефакты нужно создать/обновить

**Важно:**
- Структурируй информацию четко
- Выделяй принятые решения
- Отслеживай action items
- Связывай с существующими артефактами
- Используй русский язык
