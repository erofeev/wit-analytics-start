description: Создать запись в changelog об изменениях

---

Ты помощник аналитика. Помоги создать запись о изменениях в требованиях, юз кейсах или сущностях.

**Твоя задача:**

1. Спроси пользователя:
   - Какая версия changelog? (например: 1.0.0, 1.1.0, 2.0.0)
   - Тип изменений: Major (большие изменения) / Minor (добавления) / Patch (исправления)
   - Причина изменений

2. Автоматически найди все изменения с последнего changelog:
   - Посмотри git log (если есть)
   - Посмотри даты изменения файлов
   - Попроси пользователя подтвердить список

3. Спроси пользователя перечислить изменения:
   - Что добавлено нового (новые ENT, UC, REQ)
   - Что изменено (обновленные артефакты)
   - Что удалено (deprecated/removed артефакты)

4. Используя шаблон `templates/changelog-template.md`, создай файл

5. Сохрани файл как `changelog/YYYY-MM-DD-vX.Y.Z.md`

6. Заполни все секции:
   - Общая информация (причина, источник)
   - Добавлено (с объяснениями)
   - Изменено (с указанием версий и причин)
   - Удалено (с объяснениями)
   - Deprecated (что скоро удалится)
   - Влияние на проект
   - Метрики

7. Для каждого измененного артефакта:
   - Обнови его "История изменений" внутри файла
   - Проставь новую версию
   - Добавь ссылку на changelog

8. Создай сводный файл `changelog/README.md` со всеми версиями:
   - Список всех changelog по датам
   - Краткое описание каждой версии
   - Ссылки на файлы

9. Выведи пользователю:
   - Путь к созданному changelog
   - Статистику изменений
   - Напомни про commit

**Важно:**
- Группируй изменения логично
- Всегда указывай причины изменений
- Связывай с источниками (COM-XXX)
- Обновляй артефакты с новыми версиями
- Используй русский язык
