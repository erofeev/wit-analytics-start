description: Проверить консистентность всех документов проекта

---

Ты помощник аналитика. Проверь весь проект на ошибки, несоответствия и проблемы с трассируемостью.

**Твоя задача:**

1. Сканируй весь проект и проверяй:

   **A. Структурные проблемы:**
   - Все ли файлы используют правильные шаблоны
   - Есть ли обязательные поля в YAML frontmatter
   - Корректны ли ID (ENT-XXX, UC-XXX, REQ-F-XXX, etc.)
   - Нет ли дублирующихся ID

   **B. Проблемы со связями:**
   - Все ли ссылки указывают на существующие файлы
   - Двусторонние ли связи (A→B и B→A)
   - Нет ли "orphan" артефактов (не используются нигде)
   - Согласованы ли связи в YAML и в содержимом

   **C. Контентные проблемы:**
   - Заполнены ли обязательные секции
   - Есть ли требования без юз кейсов
   - Есть ли юз кейсы без требований
   - Есть ли сущности без использования

   **D. Версионность:**
   - Есть ли записи в "История изменений"
   - Корректны ли даты (не из будущего)
   - Указаны ли авторы

2. Создай отчет по категориям:

   ```
   ❌ КРИТИЧЕСКИЕ ОШИБКИ (нужно исправить срочно):
   - [ENT-005] Сущность не найдена, но на неё ссылается UC-010
   - [REQ-F-025] Дублирующийся ID с REQ-F-025 в другом файле

   ⚠️ ПРЕДУПРЕЖДЕНИЯ (желательно исправить):
   - [UC-008] Нет связей с требованиями
   - [ENT-003] Не используется ни в одном юз кейсе

   ℹ️ РЕКОМЕНДАЦИИ (для улучшения):
   - [REQ-NF-002] Нет критериев приемки
   - [UC-015] История изменений пустая
   ```

3. Покажи статистику:
   - Всего сущностей: X
   - Всего юз кейсов: Y
   - Всего требований: Z (функц: A, нефункц: B)
   - Всего коммуникаций: W
   - Покрытие требований юз кейсами: X%
   - Orphan артефактов: N

4. Предложи автоматические исправления:
   - "Хочешь автоматически создать обратные связи?"
   - "Хочешь создать пустые файлы для несуществующих ссылок?"
   - "Хочешь обновить все даты на корректные?"

5. Сохрани отчет:
   - Спроси: "Сохранить отчет в analysis/validation-YYYY-MM-DD.md?"

**Важно:**
- Проверяй ВСЕ файлы в проекте
- Группируй проблемы по типу и серьезности
- Давай конкретные рекомендации по исправлению
- Предлагай автоматизацию где возможно
- Используй русский язык
