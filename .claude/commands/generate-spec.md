description: Сгенерировать полное техническое задание (ТЗ)

---

Ты помощник аналитика. Создай полное техническое задание на основе всех артефактов проекта.

**Твоя задача:**

1. Спроси пользователя:
   - Для кого генерируем ТЗ? (разработчики, клиент, руководство)
   - Какой формат? (полный / краткий / executive summary)
   - Включать ли детали реализации?

2. Собери ВСЮ информацию из проекта:
   - Все сущности (`entities/`)
   - Все требования (`requirements/`)
   - Все юз кейсы (`use-cases/`)
   - Все коммуникации (`communications/`)
   - Все changelog (`changelog/`)

3. Создай структуру ТЗ:
   ```
   1. Введение
      1.1 Цель документа
      1.2 Область применения
      1.3 Термины и определения

   2. Общее описание
      2.1 Назначение системы
      2.2 Функции системы
      2.3 Категории пользователей

   3. Функциональные требования
      [Все REQ-F-XXX, сгруппированные по модулям]

   4. Нефункциональные требования
      [Все REQ-NF-XXX, сгруппированные по типам]

   5. Сценарии использования
      [Все UC-XXX с подробным описанием]

   6. Модель данных
      [Все ENT-XXX с диаграммой связей]

   7. Бизнес-правила
      [Собранные из всех артефактов]

   8. Интерфейсы
      [Если есть UI/UX заметки]

   9. Ограничения и допущения

   10. Риски
       [Собранные из требований]
   ```

4. Создай автоматически:
   - Оглавление с ссылками
   - Таблицу трассируемости (Requirement → Use Case)
   - Глоссарий терминов (из сущностей)
   - Список акторов (из юз кейсов)
   - Диаграмму связей сущностей (Mermaid)

5. Добавь метаданные:
   - Версия ТЗ (из последнего changelog)
   - Дата генерации
   - Автор/команда
   - Статистику проекта

6. Сохрани как `analysis/technical-specification-vX.Y.Z.md`

7. Опционально создай дополнительные форматы:
   - Executive Summary (краткая версия для руководства)
   - Developer Guide (для разработчиков)
   - User Stories (в формате Agile)

8. Выведи пользователю:
   - Путь к сгенерированному ТЗ
   - Статистику (страниц, требований, юз кейсов)
   - Покрытие требований
   - Пробелы (что не хватает)

**Важно:**
- Генерируй ПОЛНОЕ ТЗ со всей информацией
- Группируй логически
- Добавляй диаграммы где нужно
- Проверяй консистентность
- Используй русский язык
