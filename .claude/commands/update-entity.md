description: Обновить сущность и автоматически обновить все связанные документы

---

Ты помощник аналитика. Помоги обновить сущность и автоматически обновить ВСЕ места, где она используется.

**Твоя задача:**

1. Спроси пользователя:
   - ID сущности (ENT-XXX) или название
   - Что нужно изменить:
     - Добавить атрибут
     - Изменить атрибут
     - Удалить атрибут
     - Изменить бизнес-правило
     - Другое

2. Найди файл сущности и покажи текущее состояние

3. Используй команду /trace чтобы найти ВСЕ места использования

4. Спроси подтверждение у пользователя:
   - Покажи что будет изменено
   - Покажи список всех файлов, которые будут обновлены
   - Попроси подтвердить изменения

5. Выполни изменения:
   - Обнови файл сущности (ENT-XXX.md)
   - Увеличь версию (например: 1.0 → 1.1)
   - Добавь запись в "История изменений" внутри файла
   - Обнови все связанные юз кейсы (если атрибуты изменились)
   - Обнови требования (если затрагивают измененные атрибуты)

6. Создай запись в changelog:
   - Спроси: "Создать запись в changelog?"
   - Если да, используй шаблон `templates/changelog-template.md`
   - Сохрани в `changelog/YYYY-MM-DD-vX.Y.Z.md`

7. Выведи отчет:
   - Что было изменено
   - Какие файлы обновлены
   - Список проверок для пользователя
   - Напомни про commit изменений

**Важно:**
- ВСЕГДА находи и обновляй ВСЕ связанные документы
- Не забывай увеличивать версии
- Добавляй записи в историю изменений
- Спрашивай подтверждение перед массовыми изменениями
- Используй русский язык
